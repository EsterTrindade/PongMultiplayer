# PongMultiplayer

**Pong Multiplayer** é um projeto do meu curso do Senac, *Games 2D - Criando seu primeiro Jogo*, inspirado no clássico jogo de ping Pong, foi criado no **Construct**. Aqui, as tradicionais raquetes são substituídas por **chinelos**, e a bola de ping e pong substituída por uma *bola de vôlei*.
---

## 🚀 Funcionalidades

* **Desenvolvido sem Código**: Criado inteiramente usando o sistema de eventos visuais do Construct.
* **Física de Colisão**: Movimentação fluida da bolinha ao rebater nos chinelos.
* **Modo de Jogo**: Partida local para 2 jogadores.
* **Placar Automático**: Sistema de variáveis que computa os pontos na tela.

---

## 🛠️ Tecnologia Utilizada

* **Construct 3** (ou Construct 2) - Engine de desenvolvimento de jogos baseada em HTML5.

---

## 🎮 Como Jogar

### Controles
* **Jogador 1 (Esquerda - Chinelo Azul)**: 
  * `w` - Mover para cima
  * `s` - Mover para baixo
* **Jogador 2 (Direita - Chinelo Rosa)**: 
  * `⬆️` - Mover para cima
  * `⬇️` - Mover para baixo

### Como Rodar o Projeto
1. Baixe o arquivo disponível neste repositório.
2. Acesse o [Construct 3 Web](https://construct.net).
3. Vá em **File** > **Open** e selecione o arquivo do jogo.
4. Clique no botão **Preview** (índice de Play) para testar.
